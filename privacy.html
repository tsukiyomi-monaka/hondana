プライバシーポリシー

星くずモナカ（以下「運営者」）が運営するこのサイトと、YouTube への動画投稿に使うアプリ「星くずモナカ 動画投稿」の取り扱いです。

このサイトについて

  • このサイトは記事を探すための案内で、氏名・メールアドレスなどの個人情報を入力する場所はありません。
  • Cookie や解析ツールは使っていません。サイトは GitHub Pages で配信しており、GitHub がアクセスの記録を扱います（GitHub のプライバシーステートメント）。
  • 記事の購入と閲覧は note で行われ、その情報は note の規約に従って扱われます。

YouTube 投稿アプリ「星くずモナカ 動画投稿」について

  • このアプリは、運営者が自分の YouTube チャンネル「星くずモナカ」へ自分で作った動画を投稿するためだけに使います。運営者以外の方は使えません。
  • Google アカウントで許可された範囲（動画のアップロードと、自分のチャンネル情報の読み取り）で YouTube API サービスを使います。
  • 取得するのは、運営者自身のチャンネルの ID・名前と、投稿した動画の公開状態だけです。第三者の個人情報は取得・保存・共有しません。
  • 許可の情報（アクセストークン）は運営者の端末の中だけに保存し、外部へ送りません。許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • このアプリは YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。
